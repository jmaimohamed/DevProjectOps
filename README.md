# JETSETGO - Comprehensive Travel Management Solution

## Overview

**JETSETGO** is an all-in-one mobile application designed to streamline and simplify your travel experience. Whether you're planning a business trip or a vacation, JETSETGO provides comprehensive tools to manage every aspect of your journey efficiently and effectively.

## Key Features

### 🌍 Trip Management
Plan and organize your entire trip from start to finish with intuitive trip planning tools. Create itineraries, track your travel schedule, and manage multiple trips simultaneously with ease.

### 💰 Financial Management
Keep your travel budget under control with integrated financial tracking. Monitor expenses in real-time, set budget limits, and get detailed spending reports to ensure you stay within your financial goals.

### ⏰ Time Management
Optimize your travel schedule with smart time management features. Receive timely reminders for flights, hotel check-ins, and important reservations, ensuring you never miss a critical moment of your journey.

### 🏨 Hotel Reservations
Search, compare, and book hotels from a vast selection of accommodations worldwide. Access exclusive deals, read verified reviews, and secure the perfect place to stay for your trip.

### ✈️ Ticket Booking
Book flights, train tickets, and other transportation seamlessly within the app. Compare prices across multiple carriers and secure the best deals for your travel needs.

### 💾 Secure Data Storage
All your travel information, including bookings, receipts, and itineraries, are securely stored and easily accessible. Synchronize your data across devices for convenient access wherever you are.

## Why Choose JETSETGO?

- **All-in-One Solution**: Manage trips, finances, time, hotels, and tickets in a single platform
- **User-Friendly Interface**: Intuitive design makes travel planning effortless

## Technology Stack

This application is built using:
- **Spring Boot 3.3.4** - Modern Java framework for enterprise applications
- **Java 17** - Latest long-term support Java version
- **MySQL** - Reliable relational database management
- **Docker** - Containerized deployment for consistency and scalability
- **Maven** - Dependency management and build automation

## Getting Started

### Prerequisites
- Java 17 or higher
- Maven 3.6+
- MySQL 8.0+
- Docker (optional, for containerized deployment)

### Building the Application

```bash
mvn clean install
```

### Running the Application

#### Using Maven:
```bash
mvn spring-boot:run
```

#### Using Docker:
```bash
docker-compose up
```

The application will be available at `http://localhost:8082`

## API Documentation

Once the application is running, access the API documentation at:
- Swagger UI: `http://localhost:8082/swagger-ui.html`
